Static JSON
https://cortiezapp.github.io/api.json

Endpoint JSON statis dengan data tetap. Cocok untuk testing dan demo.

Dynamic API
https://cortiezapp.github.io/api.js

API dinamis dengan JavaScript. Waktu selalu update real-time.

Time API
https://cortiezapp.github.io/time.json

API khusus waktu dengan format lengkap: ISO, UTC, WIB, dan lokal.

Cara Menggunakan

// Menggunakan Fetch API
fetch('https://cortiezapp.github.io/api.js')
  .then(response => response.json())
  .then(data => console.log(data));

// Menggunakan Axios
axios.get('https://cortiezapp.github.io/time.json')
  .then(response => console.log(response.data));

// Menggunakan curl (terminal)
// curl https://cortiezapp.github.io/api.json
